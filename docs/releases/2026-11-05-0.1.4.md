# patch 0.1.4

এই প্যাচের সংশোধনগুলো `rockreyad/NARC-138-patch-0.1.4` branch-এর একই draft PR-এ জমবে। Linear-এর [patch 0.1.4 milestone](https://linear.app/narcdev/project/bari-khata-c6b283c05a95/issues?projectMilestoneId=f645b374-a06e-4592-b8ae-b349d97bac41)-এ প্রতিটি issue রাখুন। আরও সংশোধন ও শেষ যাচাইয়ের পরে এই PR দিয়ে `main`-এ নেওয়া হবে।

## অন্তর্ভুক্ত সংশোধন

- [NARC-138](https://linear.app/narcdev/issue/a0357438-33a2-4092-89c7-281bf23b8b96): খাতার মোট বাকির নিচে কার নামে কত টাকা বাকি দেখানো। নাম চাপলে এই খাতার সংশ্লিষ্ট লেনদেন খোলে; বিল ছাড়া শেষ কাজের পাওনা হলে ব্যক্তির কাজের হিসাব খোলে। নামহীন বিলের মূল রেকর্ড এবং কারও নামে না থাকা সমন্বয় আলাদা দেখা যায়। অন্য খাতার টাকা, অগ্রিম ও চলমান কাজের প্রতিশ্রুতি বর্তমান পাওনায় মেশে না।

## পরের সংশোধন যোগ করা

1. নতুন issue এই milestone-এ রাখুন। সংশোধনের commit এই patch branch-এ যোগ করুন, অথবা আলাদা branch-এর PR-এর base হিসেবে patch branch দিন।
2. অন্তর্ভুক্ত issue ও তার যাচাই এই নথি এবং সমন্বিত PR-এ হালনাগাদ করুন। একই প্যাচে সংশোধন যোগ করার সময় সংস্করণ `0.1.4` থাকবে।
3. সব সংশোধন শেষে চূড়ান্ত commit-এ `npm test`, `npm run build` ও `npm run release:check -- v0.1.4` চালান। প্রাসঙ্গিক পর্দা, তথ্য রেখে আবার খোলা ও ব্যাকআপ ফেরানো যাচাই করুন।
4. ব্যবহারকারীর প্রকাশের সিদ্ধান্তের পরে draft তুলে `main`-এ merge করুন। এরপর [রিলিজের নিয়ম](../RELEASING.md) অনুযায়ী সেই merge হওয়া commit-এ নতুন tag দিন।

## বর্তমান যাচাই

NARC-138-এর কোডে ২০৭টি test file-এর ২,৬৮৩টি পরীক্ষা ও `npm run build` সফল। নামভিত্তিক বাকি, নামহীন বিল, আলাদা সমন্বয়, IndexedDB পুনরায় খোলা, ব্যাকআপ ফেরানো এবং পর্দা থেকে সংশ্লিষ্ট হিসাব খোলা যাচাই হয়েছে। সংস্করণ বদলের পরের release check ও build-এর ফল PR-এ থাকবে।

## প্রকাশের অবস্থা

এটি সংশোধন জমা করার প্যাচ। `main`-এ merge, `v0.1.4` tag ও release করা হয়নি। আগে খোলা [PR #41](https://github.com/rockreyad/bari-khata/pull/41)-এর ফোনে পুরোনো খাতা খোলার সংশোধন এই branch-এ এখনও আনা হয়নি; সেটির পর্যালোচনা ও একত্র করার সিদ্ধান্ত আলাদা থাকবে। ব্যক্তিগত হিসাব বা ভাউচার এই নথি ও PR-এ থাকবে না।
