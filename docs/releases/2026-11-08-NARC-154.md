# NARC-154: কর্মীর তালিকায় টাকার অবস্থা

এই সংশোধন [patch 0.1.6-এর release PR #59](https://github.com/rockreyad/bari-khata/pull/59)-এর জন্য। মূল অনুরোধ [NARC-154](https://linear.app/narcdev/issue/NARC-154)-এ আছে।

কর্মীর তালিকায় দেওয়া টাকার নিচে এখন বাকি, অগ্রিম, চুক্তিতে বেশি দেওয়া, আমার জমা ও ফেরত পাওয়ার টাকা আলাদা ছোট ব্যাজে দেখা যায়। যে অবস্থা নেই, তার শূন্য অঙ্ক দেখানো হয় না। একই ব্যক্তির এক হিসাবে বাকি ও অন্য হিসাবে জমা থাকলে দুটোই থাকে। অগ্রিম বা জমা এবং ফেরত পাওয়ার টাকা অনুযায়ী তালিকা বাছাই করা যায়।

শুধু সাধারণ টাকা দেওয়ার রেকর্ডকে অগ্রিম বলা হয় না। চুক্তির কিস্তি চুক্তির বাকি কমায়; চুক্তির মোটের বাইরে দেওয়া অংশ ‘বেশি দিয়েছি’ হয়। চুক্তির সঙ্গে যুক্ত নয় এমন স্পষ্ট অগ্রিম, মোট সংশোধন থেকে হওয়া জমা এবং ফেরতযোগ্য টাকা নিজ নিজ হিসাব অনুযায়ী দেখায়। একই চলতি হিসাবের খাতাগুলোর আগের সমন্বয়ের নিয়ম বহাল; আলাদা account বা চুক্তির জমা অন্যটিতে চলে যায় না। ফেরত বা পুরোনো তথ্য অস্পষ্ট হলে ‘যাচাই বাকি’ থাকে এবং অনিশ্চিত জমা অনুমান করে দেখানো হয় না।

সব লেখা ও অঙ্ক `useLanguageContext()` দিয়ে বাংলা/ইংরেজিতে দেখানো হয়। [অবস্থার রঙের নিয়ম](../SEMANTIC_COLORS.md) অনুযায়ী প্রতিটি রঙের সঙ্গে স্পষ্ট নাম আছে। নতুন database লেখা, SQL migration বা আর্থিক রেকর্ড বদল নেই। সর্বনিম্ন সমর্থিত সংস্করণ `0.1.4` বহাল।

## টাকার অবস্থা ও অসম্পূর্ণ তথ্য আলাদা রাখা

চুক্তি বা বিলে আরও টাকা দেওয়ার থাকলে তালিকায় ‘আরও দিতে হবে’ লেখা হয়। মালের ধরন বাছা না থাকলেও একটি বিল বা মালের ফেরতে `needs_review` থাকতে পারে। এমন রেকর্ডের তথ্য যাচাই আর টাকার অঙ্ক না মেলা এক বিষয় নয়। এখন পরিচিত নিট অঙ্ক দেখানোর পাশাপাশি বিলের তথ্য যাচাইয়ের কথা আলাদা নিরপেক্ষ চিহ্নে থাকে; পুরোনো রেকর্ডের চিহ্ন নিজে থেকে সরানো হয় না।

বিলের সঙ্গে যুক্ত নয় এমন পুরোনো কাজের পেমেন্টকে জমা ধরা হয় না। একই খাতা বা হিসাবে অন্য মেটানো বিল থাকলেও এই নিয়ম বদলায় না। ফেরত দেওয়া মালের কারণে তৈরি হওয়া পরিচিত পাওনা, স্পষ্ট অগ্রিম, ফেরতযোগ্য টাকা ও চুক্তিতে বেশি দেওয়া আলাদা থাকে। টাকা ফেরতের উৎস অনিশ্চিত হলে সংশ্লিষ্ট হিসাবের শ্রেণি অনুমান করা হয় না; অন্য নিশ্চিত হিসাব অকারণে লুকানো হয় না। ব্যক্তির বিস্তারিত পাতার আগের সতর্কতাও বহাল থাকে।

## যাচাই

```sh
npm test
npm run build
npm run release:check -- v0.1.6
```

নমুনা তথ্যের পরীক্ষায় একই সঙ্গে বাকি/অগ্রিম/ফেরত পাওয়া, account-এর সীমা, চুক্তিতে বেশি দেওয়া, আংশিক ফেরত, সংশোধন, বাতিল ও পুরোনো রেকর্ড, সাধারণ টাকা দেওয়াকে অগ্রিম না ধরা, শূন্য অবস্থা লুকানো, ভাষা, বাছাই ও ব্যক্তির পাতা খোলা যাচাই হয়। টাকার হিসাব ও মূল input অক্ষত থাকার পরীক্ষাও আছে।

৮ নভেম্বর ২০২৬-এর যাচাইয়ে ২৩৬টি test file-এর ৩০৩৯টি পরীক্ষা, build ও release check সফল। শুধু নমুনা তথ্যের আলাদা preview-তে 320px বাংলা/light, 390px বাংলা/dark এবং 390px ইংরেজি/light দেখা হয়েছে; তিনটিতেই page overflow ও কেটে যাওয়া ব্যাজের সংখ্যা শূন্য। সাময়িক preview ফাইল অ্যাপের source বা Git-এ রাখা হয়নি।

একই দিনের পরের সংশোধনে ২৩৬টি test file-এর ৩০৭৪টি পরীক্ষা ও build সফল। অতিরিক্ত পরীক্ষায় মালের ধরন না বাছা রেকর্ডের সঙ্গে পরিচিত পাওনা, একই খাতায় মেটানো বিলের পাশের পুরোনো পেমেন্ট, ব্যবহৃত অগ্রিম, আলাদা খাতার টাকা ফেরত এবং পরের পেমেন্টে পুরোনো মোট সংশোধন থেকে নতুন জমা তৈরি না হওয়া যাচাই হয়েছে। স্থানীয় অ্যাপের সংশ্লিষ্ট সারাংশও শুধু পড়ে মিলিয়ে দেখা হয়েছে; ব্যক্তিগত আর্থিক তথ্য পরীক্ষার fixture বা Git-এ রাখা হয়নি।
