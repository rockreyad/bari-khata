# patch 0.1.6

এই branch পরের প্যাচের ভিত্তি। `package.json` ও `package-lock.json`-এর সংস্করণ `0.1.6`; প্রকাশের tag হবে `v0.1.6`।

[NARC-152](https://linear.app/narcdev/issue/NARC-152)-এর টাকা দেওয়া ও সাম্প্রতিক লেনদেনের সংশোধন আলাদা pull request দিয়ে এই branch-এ আসবে। সংশোধন মেলার পরে তার আচরণ ও যাচাইয়ের ফল এই নথিতে যোগ করতে হবে।

`release-policy.json` ও backend-এর সর্বনিম্ন সমর্থিত সংস্করণ `0.1.4` বহাল। এই প্রস্তুতিতে নতুন SQL বা তথ্যের রূপান্তর নেই।

## যাচাই ও প্রকাশ

```sh
npm test
npm run build
npm run release:check -- v0.1.6
```

প্রতিটি সংশোধনে টাকার হিসাব, IndexedDB-তে রাখা তথ্য, ব্যাকআপ ফিরিয়ে আনা এবং পর্দা থেকে তথ্য রেখে আবার খোলা যাচাই করুন। প্যাচ branch-এর সব সংশোধন মেলার পরে release pull request-এর `verify` সফল হতে হবে। এরপর `main`-এ squash merge করা commit-এ `v0.1.6` tag দিয়ে প্রকাশ করা যাবে। বিস্তারিত [রিলিজের নিয়মে](../RELEASING.md) আছে।
